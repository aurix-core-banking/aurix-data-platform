# Aurix Data Platform

Data storage and analytics platform for Aurix.

## Overview

Warehousing, data lake, and analytics infrastructure that serves as the foundation for reporting, dashboards, and data science workloads.

## Tech Stack

- PostgreSQL (OLTP replicas)
- ClickHouse / Apache Druid (analytics)
- Airflow
- dbt
